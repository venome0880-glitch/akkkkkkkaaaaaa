Put your three images in this folder (WebP, PNG or JPG – if you change the extension, update it in index.html):

  logo.webp     – round Miku-style logo (navbar, favicon, invite page)
  banner.webp   – wide neon cyan anime banner (home hero)
  artwork.webp  – square cover art (now-playing card). Copy logo.webp if you don't have a separate one.

Open index.html in a browser, or upload the whole folder to any static host (Netlify, Vercel, GitHub Pages).
Set your bot's Client ID in script.js (CONFIG.clientId) to enable the Invite button.
